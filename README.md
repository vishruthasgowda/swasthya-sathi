# 🏥 Swasthya Sathi

**Swasthya Sathi** is a healthcare-focused web application designed to make essential health information and support more accessible through a simple, user-friendly digital platform.

## 🌐 Live Demo

🔗 **[Visit Swasthya Sathi](https://swasthya-sathi.netlify.app/)**

## 📌 About the Project

Swasthya Sathi aims to provide a convenient digital healthcare experience with an intuitive interface. The project focuses on presenting health-related services and information in a clear and accessible way.

## ✨ Features

* 🏠 Clean and responsive landing page
* 📱 User-friendly interface
* 🩺 Healthcare-focused information and services
* 🖼️ Interactive and visually appealing design
* ⚡ Fast and lightweight frontend
* 🌐 Deployed and accessible online

## 🛠️ Technologies Used

* **HTML5** – Structure and content
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactivity and functionality
* **Netlify** – Deployment
* **Git & GitHub** – Version control and project hosting

## 🚀 Getting Started

To run the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/vishruthasgowda/swasthya-sathi.git
```

### 2. Navigate to the project directory

```bash
cd swasthya-sathi
```

### 3. Open the project

Open `index.html` in your browser.
